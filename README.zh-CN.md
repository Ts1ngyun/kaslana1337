# Kiana's little universe

**简体中文** · [English](README.md)

一个献给《崩坏3》琪亚娜·卡斯兰娜的非商业粉丝向网站。以**终焉之律者**的月白、紫晶与星空为主题，参考[《毕业旅行》PV](https://www.bilibili.com/video/BV1Kj411g7Lu/)的开场氛围，从列车驶向属于她的小小宇宙。

🌐 [在线访问 kianakaslana.cn](https://kianakaslana.cn)

## 功能

- **列车开场**：站点 Logo 浮现，经过车厢光影转场进入主页面。首次访问当前标签页时播放，支持跳过、Escape 退出及重播。
- **终焉主视觉**：角色立绘、星空、轨道装饰、鼠标轻微视差与滚动渐入，适配手机、平板和电脑。
- **毕业旅行回忆区**：保留原有琪亚娜图片、寄语与文案，并提供官方 PV 链接。
- **琪宝请你听听歌**：紫色播放器，收录《Da Capo》《飞鸟说》《Moon Halo》《Starfall》。支持播放、暂停、切歌、进度和音量调节；切歌时保留音量。点击播放后才请求网易云音频，仓库不保存歌曲文件，每首歌提供原平台链接。
- **FlyMe2theMoon**：本地 Q 版琪亚娜跑酷。跳过月面水晶、收集星星，每颗星星加 25 分。每局随机选择三种表情之一，暂停与继续时保留表情。
- **本地纪录**：最高分仅保存在当前浏览器；不提供账号或联网排行榜。游戏支持键盘与触屏，切换标签页、离开游戏区域或调整屏幕尺寸时自动暂停。
- **问候与祝福**：根据访客本地时间问候舰长，并提供每日祝福按钮。文案为粉丝创作，并非官方角色台词。
- **动效与无障碍**：支持减少动态效果设置、页面底部的动效开关、键盘焦点提示和状态播报，以及 **Rolling back the year** 回到顶部按钮。

部分移动浏览器通过设备音量键控制音量，播放器会显示对应提示。歌曲可用性取决于网易云音乐与访客所在地区。

## 本地运行

无需安装依赖或构建。克隆或下载仓库后，直接用浏览器打开 `index.html`。

网页素材与小游戏均为本地文件，可离线浏览和游玩；音乐、PV 链接、GitHub 与留言板需要联网。浏览器存储不可用时，游戏仅保留当前会话的纪录；清除网站数据会重置纪录。

也可以使用 Node.js 启动本地 HTTP 预览：

```sh
npm run dev
```

访问 **http://127.0.0.1:4177**。无需执行 `npm install`，可通过 `PORT` 环境变量调整端口。

### 游戏操作

| 操作 | 电脑 | 手机 / 平板 |
| --- | --- | --- |
| 开始 / 重新开始 | 开始按钮，或聚焦游戏后按空格 / ↑ / W | 开始按钮或轻触游戏区域 |
| 跳跃 | 空格 / ↑ / W、点击游戏区域或跳跃按钮 | 轻触游戏区域或跳跃按钮 |
| 暂停 / 继续 | 暂停按钮，或聚焦画布后按 P / Escape | 暂停 / 继续按钮 |

游戏只在获得焦点时接管相关按键，支持正常网页滚动，不支持二段跳。不同浏览器和网站来源的纪录互相独立，`file://` 存储行为因浏览器而异。

## 项目结构与技术

使用 HTML5、CSS3、原生 JavaScript 和 Canvas 2D，无运行时依赖；通过 GitHub Pages 托管。

```text
index.html                  当前网页
css/finality.css            终焉主题、开场动画与响应式样式
js/experience.js            开场、视差、滚动渐入与动效开关
js/site.js                  本地时间问候与祝福
js/music.js                 在线音乐播放器
js/game-core.js              跑酷物理、碰撞与计分
js/game.js                   游戏场景、操作与本地纪录
js/character.js              Q 版角色表情与动画
images/finality/             终焉立绘、PV 封面与列车素材
images/                     原有图片、角色精灵图与图标
scripts/serve.cjs            可选的本地预览服务器
tests/                      游戏测试
v2_final/                   完整 V2 存档
v1/                         原始 V1 存档
DESIGN-SOURCES.md            素材来源与生成说明
```

使用 Node.js 18 或更新版本运行游戏测试：

```sh
npm test
```
